# Stellar Bastion · 星轨要塞

三关塔防闯关游戏 · 漏怪扣血 · 稀有度掷骰 · 全球排行榜

## 玩法

- **生命**：你有 **8 点生命**（最多 10 点）。每个漏网的怪物扣 1 点。生命为 0 则本关失败。
- **三关卡**（按难度递进）：
  - **入门要塞**（Stage 1）：4 个塔位 / 8 波 / 教学难度
  - **中级要塞**（Stage 2）：5 个塔位 / 12 波 / 含飞行/自爆/精英怪
  - **终极要塞**（Stage 3）：6 个塔位 / 16 波 / 双 BOSS / 极限挑战
- **塔位系统**：每关固定 4~6 个塔位，购买/替换配件占据塔位，塔位自动激活。
- **金币**：击杀怪物掉落（普通 4~5 / 坦克 18 / 飞行 12 / 自爆 12 / 精英 80 / BOSS 400），通关每波额外奖励 50/100/200 金币。
- **稀有度掷骰**（每次刷新 3 槽位独立掷骰）：
  - ⚪ **白色** 58% — 普通
  - 🟡 **黄色** 28% — 稀有
  - 🔴 **红色** 9% — 史诗
  - 🟣 **黑色** 3% — 传说
  - 🟢 **特殊** 2% — 加血/刷新/金币/冻结/复活
- **攻击配件**（3 类）：
  - **散射**：3~8 发齐射，扇形覆盖
  - **强化**：单发高伤害，可穿透 / 溅射
  - **急速**：高频低伤 / 极高射速
- **防御配件**（3 类）：
  - **减速**：范围减速 30%~85%
  - **陷阱**：地雷式一次性爆破，可带溅射 / 吸引
  - **护盾**：替玩家阻挡 2~25 次漏怪，部分带反弹伤害
- **特殊配件**：
  - 急救包（+1 生命）、重组水晶（免费刷新）、金币风暴（+200 金币）、时间冻结（下一波全部冻结 5s）、复活十字（HP 归零时恢复至 3）

## 排名 / 分数

- **分数公式**：`通关数 × 1000 + 累计通过波数 × 10 + 剩余金币`
- 通关 3 关 + 通过所有波次（约 36 波）+ 留下金币 → 最高约 50000+ 分
- 提交后服务端返回 **全国排名** 和 **个人最佳**

## 关键技术点

- **路径跟随**：每关一条折线路径，怪物按 `segIdx / segT` 沿折线行走，可被减速 / 陷阱打断。
- **塔位槽位**：固定位置 + 自由替换。每件配件赋予塔位 `cooldown / charges / blocks` 等状态。
- **子弹模型**：每发子弹独立飞行，自动追踪最近目标，命中后可穿透 / 溅射。
- **陷阱**：购买即部署到塔位附近最近的路径点，每波自动补充一次（按 charges）。
- **护盾**：累加 `G.shields`，怪物到达玩家时优先扣盾牌，黑塔护盾带反弹 + 减速场。
- **稀有度掷骰**：3 个槽位各自独立掷骰；特殊类有 2% 概率出现且立即生效。
- **广告 mock**：5 秒倒计时 → +100 金币 → 30 秒冷却。无真实广告 SDK。
